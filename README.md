# Warehouse Management System (WMS)

Полноценное десктопное приложение для системы управления складом, разработанное на C# Windows Forms (.NET Framework 4.7.2) с использованием ADO.NET для работы с базой данных MS SQL Server.

## Требования

* ОС: Windows (или Linux с установленным Mono для компиляции)
* Среда разработки: Visual Studio 2019 / 2022 (для Windows)
* СУБД: Microsoft SQL Server (LocalDB, Express или полная версия)

## Настройка и запуск проекта

### 1. Подготовка базы данных

Проект использует MS SQL Server. По умолчанию в `App.config` настроено подключение к экземпляру `(localdb)\MSSQLLocalDB` и базе данных `WarehouseDB`.

1. Откройте **SQL Server Management Studio (SSMS)** или другой удобный инструмент (например, DataGrip или Visual Studio SQL Server Object Explorer).
2. Подключитесь к вашему серверу (например, `(localdb)\MSSQLLocalDB`).
3. Создайте новую пустую базу данных с именем `WarehouseDB`:
   ```sql
   CREATE DATABASE WarehouseDB;
   ```
4. Выберите созданную базу данных и выполните SQL-скрипт `schema.sql`, который находится в корне папки `Warehouse/`. Этот скрипт создаст все необходимые таблицы и добавит начальных пользователей с захешированными паролями.

*Примечание:* Если вы используете другой сервер (не LocalDB), не забудьте обновить строку подключения в файле `Warehouse/App.config`:
```xml
<connectionStrings>
    <add name="WarehouseDB" connectionString="Data Source=ВАШ_СЕРВЕР;Initial Catalog=WarehouseDB;Integrated Security=True" providerName="System.Data.SqlClient" />
</connectionStrings>
```

### 2. Сборка проекта

#### В Windows (Visual Studio)
1. Откройте решение `Warehouse.slnx` или файл проекта `Warehouse/Warehouse.csproj` в Visual Studio.
2. Нажмите `F5` или выберите `Сборка -> Собрать решение` для компиляции и запуска приложения.

#### В Linux (используя Mono)
1. Убедитесь, что у вас установлен `mono-devel`.
2. Перейдите в корневую директорию проекта.
3. Выполните команду сборки:
   ```bash
   xbuild Warehouse/Warehouse.csproj
   ```
4. После успешной сборки, исполняемый файл будет находиться по пути: `Warehouse/bin/Debug/Warehouse.exe`. Запустить его можно командой:
   ```bash
   mono Warehouse/bin/Debug/Warehouse.exe
   ```

### 3. Авторизация (Ролевая модель)

В приложении реализована ролевая модель доступа (RBAC). При запуске откроется окно авторизации. В скрипте `schema.sql` уже созданы две учетные записи:

* **Роль: Администратор**
  * Логин: `admin`
  * Пароль: `admin`
  * Доступен полный функционал, включая удаление справочников и раздел "Аналитические отчеты".

* **Роль: Кладовщик**
  * Логин: `store`
  * Пароль: `storekeeper`
  * Доступ ограничен: скрыты кнопки удаления товаров и контрагентов, а вкладка "Аналитические отчеты" полностью недоступна.

## Особенности архитектуры

* Приложение построено на строгом использовании **ADO.NET** (объекты `SqlConnection`, `SqlCommand`, `SqlDataAdapter`).
* Все запросы параметризованы (`SqlParameter`) для предотвращения SQL-инъекций.
* Неуправляемые ресурсы гарантированно освобождаются за счет использования конструкций `using`.
* Оптимизированная In-Memory фильтрация (на базе объекта `DataView`) позволяет осуществлять мгновенный поиск без дополнительных обращений к БД.
* Интерфейс работы с операциями на складе реализован по паттерну Master-Detail (взаимосвязанные таблицы "Заказы" и "Движения товаров").
